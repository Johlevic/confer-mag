## 📋 Descripción

Sistema de registro y certificados digitales para la conferencia magistral del curso de **Biotecnología**, organizada por la Facultad de Ciencias Biológicas de la Universidad Nacional de Trujillo.

## ✨ Características

| | |
|---|---|
| ✅ Registro con validación en tiempo real | 📄 Certificados digitales automáticos |
| 📊 Panel de administración con búsqueda | 📤 Exportación a CSV |
| 📱 Diseño responsive con sidebar adaptable | 🔔 Notificaciones toast |
| 🚦 Rate limiting en API | 📧 Correo de confirmación automático (SMTP) |
| 🔍 SEO / Open Graph / PWA | 🧪 Tests unitarios (Vitest) |

## 🛠️ Stack

| Tecnología | Uso |
|---|---|
| **Next.js 16** (App Router) | Framework frontend + API routes |
| **TypeScript 5** | Tipado estático |
| **Tailwind CSS 4** | Estilos utilitarios |
| **PostgreSQL** (Vercel) | Base de datos |
| **Zod 4** | Validación de formularios |
| **Nodemailer** | Envío de correos (Gmail SMTP) |
| **Vitest** | Tests unitarios |
| **react-select** | Selector de países con búsqueda |

## 🚀 Inicio rápido

```bash
npm install
npm run dev      # http://localhost:3000
```

## 🧪 Tests

```bash
npm run test
```
